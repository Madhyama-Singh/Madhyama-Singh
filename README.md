### 🇮🇳 [Indian Economic Policy Sentiment Analysis](https://github.com/YOUR_USERNAME/indian-economic-policy-sentiment-analysis)

> *NLP · FinBERT · Streamlit · BERTopic · spaCy · Transformers*

Built a real-time NLP system analyzing **2,00,500 Indian financial
news headlines** (2017–2021) using a multi-model pipeline combining
FinBERT, VADER, and Flair for sentiment scoring, BERTopic for topic
modeling, and spaCy for named entity recognition. Deployed as a
**7-page interactive Streamlit dashboard** with real-time headline
prediction, historical sentiment index, event study, and model
comparison.

**Technical Highlights:**
- Multi-model NLP pipeline — FinBERT + VADER + Flair + BERTopic + spaCy
- Processed 40,423 headlines across 1,552 days on Tesla T4 GPU
- Event study validated model against 7 real historical economic events
- 72.87% polarity agreement between two independent models
- Full Streamlit deployment with real-time inference

`FinBERT` `BERTopic` `spaCy` `VADER` `Streamlit` `Plotly`
`Transformers` `HuggingFace` `Pandas` `GPU` `Python`
